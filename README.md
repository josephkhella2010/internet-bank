# Internet Bank

A simple Internet Bank application built with **Node.js, TypeScript, Express, and Zod**.

## Requirements

* Node.js
* npm

## Run the project

Start the development server with:

```bash
npm run dev
```

The server will run on:

```text
http://localhost:3000
```
